# Noor Architects — Masjid Landing Page

A simple, self-contained landing page for a fictional architectural practice
that designs and builds masjids for Dawoodi Bohra mumineen.

## Files

- `index.html` — page structure and content
- `styles.css` — styling (typography, layout, responsive)
- `script.js` — sticky header, mobile nav, contact form handling

## Running locally

It is plain static HTML — open `index.html` directly in a browser, or serve
the folder with any static server, for example:

```bash
cd masjid-landing
python3 -m http.server 8080
# then visit http://localhost:8080
```

## Sections

1. Sticky header + nav
2. Hero with tagline and jamaat-oriented stats
3. About the practice
4. Services (masjid design, jamaatkhana, renovation, interiors, feasibility, construction)
5. Process (niyyat → iftitah, five steps)
6. Selected projects (SVG-illustrated cards)
7. Quranic quote (At-Tawbah 9:18)
8. Contact form
9. Footer
